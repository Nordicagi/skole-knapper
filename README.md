# Skole-knapper

A small Obsidian plugin with buttons for a school vault: Ny…, Ny tanke, Ny time, Notatbok, Ny side, Oppgave, Hjelp,
Lag notat and Lenk. It also has an experimental fast pen for Excalidraw, off until you run the command
"Rask penn i Excalidraw (på/av)" on that device.

It is built for one vault's folders and is shared here only so it can be installed with BRAT.

## Install on a device

1. Install **BRAT** (Obsidian42 - BRAT) from Community plugins and switch it on.
2. BRAT → **Add beta plugin** → `Nordicagi/skole-knapper` → Add.
3. Switch on **Skole-knapper** under Community plugins.

BRAT checks for new versions when Obsidian starts.

## Source

`main.js` is a built file. The source scripts live in the vault (`Machine/Skript`); `bygg-knapper.js` builds the plugin
and `publiser-knapper.js` publishes a new release here.
